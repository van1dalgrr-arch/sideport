# sideport

[English](README.md) | **Русский**

Открытый сайдлоадер IPA для iPhone, написанный на Rust.

Цель проекта: бесплатная замена Sideloadly. Установить IPA на свой iPhone с бесплатным Apple ID и автоматически переподписывать приложение до того, как истечёт 7-дневная подпись.

> **Статус: ранняя разработка.** Устанавливать приложения sideport пока не умеет. Сейчас он читает IPA-файлы и общается с подключённым iPhone. План работ ниже.

## Что работает сейчас

| Команда | Что делает |
|---|---|
| `sideport info <file.ipa>` | Открывает IPA, находит `Info.plist` и выводит bundle id |
| `sideport devices` | Показывает подключённые iPhone и выводит свойства устройства, полученные от `lockdownd` |

```console
$ sideport info app.ipa
bundle id: com.example.app

$ sideport devices
00008120-000A1B2C3D4E5F6A (USB), id 1
<?xml version="1.0" encoding="UTF-8"?>
...
```

## Как это устроено

sideport сам говорит на протоколах Apple, без библиотек Apple и без libimobiledevice:

1. Подключается к демону `usbmuxd` через Unix-сокет `/var/run/usbmuxd` и запрашивает список устройств.
2. Просит `usbmuxd` открыть туннель до порта 62078 на телефоне, где слушает сервис `lockdownd`.
3. Отправляет в этот туннель plist-запросы и читает ответы.

Весь код асинхронный и работает на [tokio](https://tokio.rs).

## Сборка

Нужны macOS и стабильный Rust (1.85 или новее).

```sh
git clone https://github.com/van1dalgrr-arch/sideport
cd sideport
cargo build --release
./target/release/sideport devices
```

На Linux с запущенным `usbmuxd` тоже должно работать, но это не проверялось.

## Ограничения бесплатного Apple ID

Эти ограничения задаёт Apple, они одинаковы для всех сайдлоадеров:

- подпись действует 7 дней;
- одновременно на устройстве может быть до 3 установленных так приложений;
- до 10 новых App ID в неделю.

## Отказ от ответственности

sideport не связан с Apple и Sideloadly. Устанавливайте только те приложения, на использование которых у вас есть право.
